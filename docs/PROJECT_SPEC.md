# 專案規格

本專案建立全本機執行的台股新聞情緒分析與投資組合研究平台。核心流程是將新聞文字透過 LLM 轉換為結構化情緒因子，再和股價資料依交易日對齊，檢驗情緒與未來報酬是否有關。

## 研究問題

1. 台股新聞情緒是否與未來 1 日、3 日、5 日報酬有關？
2. LLM 是否適合判斷台股新聞語境？
3. 個股新聞、大盤新聞與產業新聞是否應分開處理？
4. 將情緒分數轉成投資訊號後，是否能優於基準策略？

## 原則

- 全部本機執行
- 使用 SQLite
- 不登入、不部署、不使用雲端資料庫
- 不宣稱可穩定預測股價
- 如實呈現無效或弱效果結果

## 本機網址

- Frontend: http://localhost:3000
- Backend: http://localhost:8000
- Database: `backend/data/twstock_sentiment.db`
